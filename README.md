# 魔法圖書館：典籍歸序

> 治癒解謎向魔法休閒遊戲 — 擔任上古隱世聖典圖書館唯一繼任管理員，透過整理、修復、歸序因大戰動盪紊亂的上古魔法典籍，挽回崩壞的魔星魔法大陸法則。

## 遊戲簡介

在第一次魔法世界大戰後，消失萬年的上古聖典圖書館重新現世。館內億萬上古典籍因大戰的魔力暴動與空間撕裂而集體失控——書頁顛倒、章節錯亂、符文潰散、分類混雜。典籍承載的是世界魔法本源法則，書籍一亂，整個魔星大陸隨之持續崩壞。

玩家是上古圖書館唯一的天命繼任管理員，擁有專屬天賦「溯序之瞳」，無需征戰殺伐，只需歸正萬千錯亂古籍，重織世界魔法法則。

## 玩法特色

### 七大解謎玩法

| 玩法 | 說明 |
|---|---|
| 書頁排序 | 透明古書翻頁，將泛黃紙條貼回正確頁位，貼完統一檢查 |
| 殘頁拼接 | 碎片吸附拼合戰火損毀的殘頁 |
| 符文淨化 | 依序點亮／連線淨化被暴戾魔力污染的符文 |
| 法則歸類 | 將元素小書拖入對應分類書架 |
| 古籍解密 | 根據線索填空／選擇正確含義 |
| 書架歸位 | 依標籤與紋理歸位典籍 |
| 法則約束排列 | 依「必須相鄰／必須隔一格／不可鄰接」等約束排列元素位次 |

### 五大典庫 · 27 關

- **元素典庫**（8 關，前期）— 風火水土雷基礎法則
- **星辰典庫**（5 關，中期）— 天象時序星軌
- **生靈典庫**（5 關，治癒向）— 萬物生機自然生態
- **古秘典庫**（4 關，劇情向）— 上古文明與圖書館起源
- **禁忌典庫**（5 關，後期高難）— 戰爭本源與空間秘術

典庫循序解鎖，完成前一典庫 3 關後解鎖下一庫。

### 收集與養成

- **典籍圖鑑**：修復後解鎖古籍資料與世界觀片段
- **書靈喚醒**：稀有典籍完整修復後喚醒法則書靈
- **館藏升級**：消耗秩序值解鎖塵封區域、提升收益
- **自動存檔**：進度保存於瀏覽器 localStorage，刷新可繼續

## 世界觀

### 大陸與圖書館

數千年前，上古法師為留存世間一切魔法本源，耗費百年打造上古聖典圖書館——這是維繫整片大陸魔法根基的「法則核心載體」。竣工後施下終極隱世結界，圖書館脫離大陸地表、藏匿於空間夾縫之中，靜靜封存萬年。

### 第一次魔法世界大戰

各族為爭奪魔法資源爆發席卷全境的大戰。高階魔法對轟、禁忌術式泛濫，長年累月的暴力強行擊碎了隱世結界殘層。大戰終末，消失萬年的上古圖書館緩緩現世，懸浮在魔星大陸中央空域。世人將大陸正式定名——魔星魔法大陸。

### 典籍混亂的起因

大戰的狂暴魔力穿透結界沖刷館內典籍，劇烈空間震盪打碎每本書的「法則錨點」。書頁顛倒、符文潰散、魔力互斥——典籍一亂，整個魔星大陸隨之開始持續崩壞。

### 玩家的使命

大戰落幕百年後，玩家作為上古圖書館唯一的天命繼任管理員甦醒，是唯一能感知並修復法則典籍的人。從修復基礎元素典籍開始，逐步解開上古秘聞，查清一戰崩壞的深層原因，最終修復本源典籍，徹底拯救魔星大陸。

## 書籍錯亂類型

- **戰火紊亂**：書頁內容扭曲、符文沾染暴戾魔力
- **排序錯亂**：書頁順序顛倒、章節錯位
- **殘缺破損**：書頁遺失、典籍缺損
- **屬性混雜**：不同系別魔法互相摻雜、法則衝突
- **封印鬆動**：上古禁忌典籍封印被擊碎、亂力外泄
- **塵封失語**：萬年封存古籍文字模糊、法則沉寂
